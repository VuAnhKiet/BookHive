# Book Hive (This is an ongoing project!)

A platform that allows users to lent or borrow books from book hubs through the website. If a requested book is located in a distant book hub, the system uses a community-based delivery network where volunteers transport the book across cities. Instead of traditional shipping, relay chains are formed using people who are already planning to travel.

---

## Core Concept
- Users can lend books on the website for others to borrow with a fee.
- Users can request books from remote book hub if the book is not available locally.
- Volunteers register their travel routes.
- The system automatically matches routes to form a multi-step relay chain.
- Books are passed between volunteers until they arrive at the destination library.
- Users pick up the book locally.

---

## Example Delivery Flow

1. User requests a book
2. System identifies the source book hub
3. Matching volunteers are found
4. Relay chain is created
5. Volunteers carry the book step-by-step
6. Book arrives at destination library
7. User is notified and picks it up

---

## Example Relay Route

1. Book hub A (Da Nang)
2. Alice (Volunteer): Da Nang → Hue
3. Bob (Volunteer): Hue → Hanoi
4. Book hub B (Hanoi)

---

## User Roles

### Lender
- Can lend books on the website for others to borrow with a fee.
   
### Reader
- Search for books across website
- Request book transfers
- Pick up books at destination book hub

### Book hub Staff
- Manage book inventory
- Handle check-in/check-out of books
- Checking books's condition

### Volunteer Courier
- Register for volunteer
- Register travel routes (origin, destination, date, capacity)
- Carry books between cities
- Update delivery status

### Admin
- Handle disputes and lost books
- Monitor system activity
- Manage users and moderation
